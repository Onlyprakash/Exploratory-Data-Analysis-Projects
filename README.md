# ✈️ Flight Price Analysis Project
# ╔══════════════════════════════╗
║   ✈️ SKY FARE ANALYTICS ✈️   ║
║  Aviation • Routes • Prices ║
╚══════════════════════════════

## 📌 Project Overview

This project focuses on analyzing flight ticket pricing data to identify the major factors affecting airfare prices such as airline, source, destination, stops, duration, and travel timing.

## 🎯 Objectives

* Perform data cleaning and preprocessing
* Extract meaningful time-based features
* Analyze pricing patterns across airlines
* Understand how stops and duration impact fares
* Prepare dataset for future Machine Learning models

## ⚙️ Steps Performed

* Handled missing values
* Converted datetime columns
* Extracted hours and minutes from duration/time columns
* Feature engineering on categorical variables
* Univariate and multivariate analysis
* Data visualization using charts and graphs

## 📊 Key Insights

* Flights with fewer stops generally cost more
* Certain airlines maintain consistently higher fares
* Duration and travel timing strongly affect ticket prices
* Peak travel hours influence pricing trends

## 🧰 Libraries Used

```python
pandas
numpy
matplotlib
seaborn
```
